## 1. コア・ディレクトリ構成

本リポジトリは、以下の主要コンポーネントで構成されています。

- **`/governance/`**: システム全体の憲法、行動規範、およびワークスペース統合ガイド。

- **`/workflows/`**: 設計から検証、バグ修正にいたる標準的な開発プロセス。
